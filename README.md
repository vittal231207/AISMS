# AISMS

A Python-based Academic Information &amp; Student Management System for managing student, staff, academic, and authentication workflows.
=======

AISMS is a Python-based Academic Information & Student Management System designed to manage student and staff information efficiently.

## Features

- Student registration and profile management
- Staff profile management
- Student and staff login
- Password reset using OTP
- Student profile photos
- Indian PIN code lookup
- Secure password hashing
- SQLite database integration
- Academic information management

## Tech Stack

- Python
- SQLite
- Tkinter
- bcrypt
- CSV

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/vittal231207/AISMS.git
cd AISMS
```

### Run the Project

```bash
python3 aismsprojj.py
```

## Database

AISMS uses SQLite for storing and managing application data. The database is initialized automatically when the application starts.
